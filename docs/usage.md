# เริ่มใช้ Binance TH Assistant

## ลองด้วยเงินจำลอง

1. เปิด **Binance TH** ใน Ponpoko แอปเริ่มที่ **เงินจำลอง** มียอดตั้งต้น 10,000 บาทและไม่ต้องเชื่อมบัญชี
2. ตารางจัดอันดับเหรียญจากผลตอบแทน 30 วันใน Binance Global คอลัมน์ **เทียบ BTC** บอกว่าผลต่างกันกี่จุดเปอร์เซ็นต์ กด **ลองแผนจากอันดับ** หรือเลือกคู่เงินบาทเอง ถ้าไม่มีแผนผ่านเกณฑ์ ยังเลือกคู่เองได้
3. กด **ตรวจใบคำสั่ง** ดูราคา จำนวน ค่าธรรมเนียม และจุดทบทวน แล้วกด **ยืนยันจำลอง** เมื่อต้องการขาย ให้กด **เตรียมขาย** ในหน้าสถานะ

## ซื้อขายเงินจริงบน macOS

ขณะนี้เส้นทางเงินจริงเป็น **pilot สำหรับ BTC/THB** ใช้บัญชีย่อย Binance TH ของคุณเอง สร้าง API key ที่ให้สิทธิ์อ่านข้อมูลและ Spot เท่านั้น หากต้องการดูยอดก่อน ให้รัน `connect` จากโฟลเดอร์โปรเจกต์

```sh
./dist/bin/binance-th-backend connect
```

เมื่อต้องการเข้าร่วม pilot ให้รันคำสั่งนี้แทน กรอก key และ secret ใน Terminal ซึ่งจะซ่อนอักขระและเก็บค่าใน macOS Keychain อนุญาต Keychain เฉพาะเมื่อระบบถามจากตัว backend ที่คุณติดตั้ง

```sh
./dist/bin/binance-th-backend connect-pilot
```

จากนั้นเปิด **เงินจริง** ใน surface กด **โหลดสถานะ** และตั้งเพดานต่อคำสั่ง ต่อสถานะ ขาดทุนต่อแผน และขาดทุนต่อวัน ตรวจใบคำสั่งแล้วกด **ยืนยันซื้อด้วยเงินจริง** หรือ **ยืนยันขายด้วยเงินจริง** ทุกครั้ง

## อ่านสถานะก่อนกดซ้ำ

- ราคา **limit** คือราคาสูงสุดที่ยอมจ่ายตอนซื้อ หรือราคาต่ำสุดที่ยอมรับตอนขาย ส่วนที่จับคู่ไม่ได้ทันทีจะหมดอายุ ตรวจยอดที่จับคู่จริงแม้รายการขึ้นว่า **หมดอายุ**
- **จุดทบทวน** เป็นราคาที่ให้คุณกลับมาดูแผน คุณต้องกดยืนยันขายเอง รุ่นนี้ยังไม่มีคำสั่ง stop ที่ exchange และไม่มีโหมดอัตโนมัติ
- ถ้าขึ้น **ยังไม่ทราบผล** ให้กด **ตรวจผลเดิม** ในประวัติ ถ้ายังไม่ชัด ให้เปิด Binance TH ตรวจสถานะคำสั่งและยอด
- **หยุดเปิดไม้ใหม่** ปิดการซื้อเพิ่มทันทีใน surface ส่วนคำสั่งที่ส่งไปแล้วอาจยังจับคู่ได้ ให้ตรวจผลเดิมและยอดที่เหลือก่อนขายหรือปิดแอป
- การขายผ่าน surface ใช้เฉพาะเหรียญที่ซื้อผ่าน surface นี้ เศษที่ต่ำกว่าขั้นต่ำต้องตรวจที่ Binance TH

หากต้องการลบข้อมูลเชื่อมต่อในเครื่อง ให้ตรวจรายการค้างที่ Binance TH ก่อน แล้วรัน `./dist/bin/binance-th-backend disconnect` การเพิกถอน key ทำใน API Management ของ Binance TH
