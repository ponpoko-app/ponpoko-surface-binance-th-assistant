# Binance TH Assistant

Surface สำหรับหาโอกาสจาก cross-sectional momentum ของ Binance Global และส่งคำสั่ง spot คู่เงินบาทจริงไปที่ Binance TH ด้วยบัญชีของผู้ใช้เอง

**สถานะ:** มี bundle สำหรับ Ponpoko พร้อมโหมด paper และเส้นทางส่งเงินจริงแบบยืนยันสำหรับ pilot BTC/THB บน macOS การเปิดให้ใช้งานวงกว้างรอการทดสอบซื้อและขายกับบัญชีจริง

## รุ่นแรก

1. เปิดหน้าแผนได้ทันที ใช้ข้อมูลตลาดสาธารณะและลอง `paper` ด้วยเงินจำลองได้โดยไม่ต้องสร้าง API key
2. ดูอันดับผลตอบแทน 30 วันจากคู่ USDT บน Binance Global ของเหรียญที่ซื้อขายกับ THB บน Binance TH ได้ พร้อมต้นทุน สภาพคล่อง และเหตุผลที่คู่ถูกคัดออก
3. เลือกแผนจากอันดับ หรือเลือกคู่และกำหนดราคาเอง แล้วดูจำนวนที่ส่งได้จริงและเงื่อนไขออกก่อนตัดสินใจ
4. เชื่อม Binance TH เมื่อพร้อมใช้เงินจริง ในโหมด `confirm` ผู้ใช้ตรวจและยืนยันคำสั่งซื้อหรือขายทุกครั้ง ใช้ราคา limit และดูผลจาก exchange รวมถึงยอดที่จับคู่ได้บางส่วน
5. หน้าสถานะบอกว่าถือเท่าไร ขายได้เท่าไร จุดออกเป็นแผนหรือคำสั่งที่ exchange รับแล้ว และเมื่อไหร่ต้องไปตรวจที่ Binance TH

| โหมด | ขอบเขต |
| --- | --- |
| `paper` | จำลองบนราคาฝั่ง Binance TH แยกยอดเงินและประวัติจากเงินจริง |
| `confirm` | pilot BTC/THB ใช้ Limit IOC และยืนยันทุกครั้ง คู่และชนิดคำสั่งเพิ่มเติมต้องผ่าน pilot แยก |
| `auto` | รุ่นถัดไป ผู้ใช้เปิดเป็นราย session และต้องพิสูจน์การคุ้มครองสถานะที่ exchange ก่อนเปิดใช้ |

เงินอยู่ที่ Binance TH และ secret อยู่ในที่เก็บของระบบปฏิบัติการ Binance Global ใช้เฉพาะข้อมูลสาธารณะ ขอบเขตเป็น spot ของบัญชีตนเองเท่านั้น

## ติดตั้งจากโฟลเดอร์นี้

```sh
npm ci
npm run build
npm run check
npm test
```

ต้องมี Bun สำหรับ build และ test ผล build อยู่ใน `dist/` เลือก **Install local build** ใน Ponpoko → Settings → Development หรือใช้ `ponpoko surface-install --bundle ./dist` แล้วเปิด **Binance TH** จากตัวเลือก surface
